# برنامج استقبال ويندوز — جسر إشعارات إيداع جيب
(Jeeb Deposit Bridge — PC Windows Receiver)

برنامج استقبال محلي خفيف ومكتوب بلغة Python 3 يعتمد فقط على المكتبات القياسية لنظام ويندوز دون الحاجة لتثبيت أي حزم خارجية معقدة.

## المميزات:
1. **واجهة مستخدم رسومية (Tkinter / Fluent-inspired):** تعرض السجلات فور وصولها دون الحاجة لتحديث الصفحة.
2. **خادم HTTP محلي مدمج:** يعمل على المنفذ `8765` ويستمع لطلبات تطبيق هاتف الكاشير.
3. **رمز ربط أمني (Pairing Token):** يتم توليده عشوائيًا عند أول تشغيل لمنع أي جهاز غير مصرح به على الشبكة من إرسال بيانات وهمية.
4. **تخزين دائم في SQLite3 (`deposits.sqlite3`):** يحفظ جميع الإشعارات مع وقت وصولها.
5. **منع التكرار (Deduplication):** يمنع تكرار تسجيل نفس العملية باستخدام بصمة فريدة `SHA-256`.
6. **تنبيه صوتي:** نغمة تنبيه عند وصول إيداع جديد للكاشير لتنبيهه دون النظر المستمر للشاشة.
7. **تصدير البيانات:** تصدير السجلات بصيغة JSON أو CSV بضغطة زر.

## طريقة التشغيل:
1. تأكد من تثبيت Python 3.10 أو أحدث.
2. انقر نقرًا مزدوجًا على `start_windows.bat`.
3. انسخ رمز الربط (Token) الظاهر على الشاشة وأدخله في تطبيق الكاشير على الهاتف.
4. تأكد من أن الهاتف والكمبيوتر متصلان بنفس شبكة Wi-Fi.

## المسارات البرمجية (API):
- `GET /api/status` — التحقق من جاهزية الخادم وصلاحية رمز الربط.
- `POST /api/deposit` — استقبال الإشعار وتخزينه ومنع التكرار.
